DeepFilterNet3 • PipeWire • WaveRT • CoreAudio

🔵 Fedora / RHEL / CentOS (DNF)

Instalação direta e atualizações automáticas via dnf:

# 1. Adicionar o repositório
sudo dnf config-manager addrepo --from-repofile=https://joaorura.github.io/clearcore/rpm/clearcore.repo

# 2. Instalar o Clearcore
sudo dnf install -y clearcore

🟠 Debian / Ubuntu / Linux Mint (APT)

Instalação nativa via apt:

# 1. Adicionar o repositório do Clearcore
echo "deb [trusted=yes] https://joaorura.github.io/clearcore/apt stable main" | sudo tee /etc/apt/sources.list.d/clearcore.list

# 2. Atualizar índices e instalar
sudo apt update && sudo apt install -y clearcore

🪟 Windows (WinGet)

Instalação de comando único no Windows 10/11:

winget install joaorura.Clearcore
