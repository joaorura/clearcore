- **R0 (process — mandatory):** SDD requires dispatching implementer subagents, but this OpenCode harness exposes no implementer subagent tool (only `call_omo_agent`→explore/librarian, read-only). The controller therefore executes mechanical, isolated, self-verifying edits directly and records a review gate (cargo check/test + ledger) after each, emulating the implementer→reviewer round-trip for low-risk steps. Substantive design/implementation (T2 OrtBackend: realtime audio, zero-alloc, GRU continuity, FIM) is held to full verification discipline. Stops only on the four named classes (here: none — no irreversible/destructive/security/side-effecting action in T1). Cost if wrong: context pollution on mechanical edits; mitigated by scoped verification + tiny diffs.
